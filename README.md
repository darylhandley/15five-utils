# 15Five Utils Shell

A simple interactive command-line shell application built with Kotlin and Maven. This shell serves as the foundation for future integration with the 15Five application.

## Features

- **Interactive Shell**: Command-line interface with colorized output for better readability
- **Color-coded Interface**: 
  - Blue prompt (`15five>`)
  - Green success messages
  - Red error messages  
  - Yellow command highlights
  - Visual separators between commands
- **Built-in Commands**:
  - `echo <message>` - Echo the message back to the shell
  - `help` - Display available commands
  - `quit` / `exit` - Exit the shell

## Building and Running

### Authentication

15Five's official Public API needs an admin-only, company-wide key, so this tool uses the same internal
web endpoints as the browser and authenticates with your browser's `sessionid` cookie. Only that one value
is needed — CSRF tokens are generated by the app (15Five's Django CSRF check is double-submit and not tied
to the session).

1. Log into https://sonatype.15five.com in Chrome.
2. Open DevTools → **Application** → **Storage → Cookies → https://sonatype.15five.com**.
3. Filter for `sessionid` and copy its **value**.
4. Start the shell and run `auth`. It reads the value from the clipboard, verifies it against 15Five, and
   only then saves it to `~/.15fiveutils/session` (chmod 600, outside the repo). You can also run
   `auth <value>`. Pasting `sessionid=<value>` or a whole cookie header also works.

On startup the shell reports whether the session is valid. When it expires, any command prints
`15Five session expired or invalid ... run 'auth'` — copy a fresh cookie and run `auth` again; no restart needed.

`auth status` checks the session (read) and the write path (a no-op CSRF probe that updates nothing).

> Legacy: if `~/.15fiveutils/session` does not exist, `fifteen.five.sessionid` in `./application.properties`
> is still read. Running `auth` once moves you to the new location. `fifteen.five.csrfmiddlewaretoken` is no
> longer used.

### Compile the Application

```bash
mvn compile
```

### Run the Shell

```bash
mvn exec:java
```

### Alternative: Compile and Run in One Command

```bash
mvn compile exec:java
```

## Usage

Once the shell starts, you'll see:

```
15Five Utils Shell - Type 'help' for commands or 'quit' to exit
────────────────────────────────────────────────────────────
15five> 
```

### Example Session

```
15five> help
Available commands:
  help           - Show this help
  quit/exit      - Exit the shell
──────────────────────────────
15five> echo Hello World!
Hello World!
──────────────────────────────
15five> quit
Goodbye!
```

## Development Notes

The application uses ANSI escape codes for terminal colors. If you're running in an environment that doesn't support 
ANSI colors, you may see escape sequences in the output instead of colored text.
